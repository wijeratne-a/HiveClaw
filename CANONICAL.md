# Canonical checkout

Use **only** this repository for development:

`~/dev/HiveClaw`

- Virtualenv: **`~/dev/HiveClaw/.venv`** (Python ≥ 3.11).
- Do not maintain a second HiveClaw clone (e.g. `~/Desktop/HiveClaw`) for day-to-day builds unless it is disposable.

See **`scripts/README.md`** for setup, `make python`, and daemon commands.
